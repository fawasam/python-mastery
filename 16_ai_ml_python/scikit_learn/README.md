# Machine Learning with Scikit-Learn

## What You Will Learn
- Train/Test Splitting (`train_test_split`)
- Training Supervised Learning Models (Logistic Regression, Random Forest Classifier)
- Evaluating Model Performance (Accuracy, Precision, Recall, F1 Score)
- Building Scikit-Learn `Pipeline` workflows with `StandardScaler`

## Why This Matters
Scikit-Learn is the industry standard Python library for traditional Machine Learning. Its unified `fit()`, `transform()`, and `predict()` API makes training and evaluating models simple and reproducible.

## Pipeline Workflow

```text
 Raw Features → [ StandardScaler ] → [ LogisticRegression ] → Prediction
```

# Vector Embeddings and Semantic Search

## What You Will Learn
- What vector embeddings are (dense floating-point representations capturing semantic meaning)
- Generating TF-IDF / Bag of Words vector representations using `scikit-learn`
- Performing K-Nearest Neighbors (KNN) semantic search over vector embeddings
- Comparing TF-IDF vs dense LLM embeddings

## Why This Matters
Modern AI applications (RAG systems, recommendation engines, semantic document search) convert unstructured text, images, and audio into numerical vector embeddings to query similar concepts using vector math.

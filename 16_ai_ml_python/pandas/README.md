# Pandas for ML Feature Preparation

## What You Will Learn
- Preparing tabular data for Scikit-Learn model pipelines
- Separating target variables ($y$) from predictor feature matrices ($X$)
- Handling class imbalance with frequency sampling
- Converting categorical string columns into numeric indices

## Why This Matters
Machine learning models cannot directly consume raw database tables with string labels or missing values. Pandas serves as the primary data wrangling layer between raw SQL/CSV sources and ML training pipelines.

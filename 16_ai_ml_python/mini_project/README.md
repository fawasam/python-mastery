# Mini Project: Enterprise RAG & AI Agent Knowledge Engine

## Overview
In this mini project, you will build an end-to-end RAG (Retrieval-Augmented Generation) & Agent execution engine combining TF-IDF vector embeddings, cosine similarity, prompt grounding, tool dispatching, and safety input guardrails.

## Features
1. **Safety Guardrail**: Sanitizes PII and checks against prompt injection attacks.
2. **Vector Retrieval**: Computes TF-IDF embeddings to find relevant knowledge passages.
3. **Agent Executor**: Synthesizes grounded answers and dispatches tool execution.

## Running the Engine
```bash
python main.py
```

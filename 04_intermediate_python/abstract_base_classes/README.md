# Topic: Nominal Interfaces with Abstract Base Classes (`abc.ABC`)

## What You Will Learn
- Nominal subtyping contracts vs structural Protocols.
- Registering virtual subclasses using `ABC.register()`.
- Combining `@classmethod` and `@property` with `@abstractmethod`.

## Core Concepts
1. **Nominal Subtyping**: Requires explicit inheritance or registration to satisfy type hierarchy.
2. **`ABC.register(Class)`**: Allows existing classes to register as virtual subclasses of an ABC without altering inheritance trees.

# Project 01: Production CLI Calculator

## Overview
A production-grade command-line calculator supporting arithmetic expressions, interactive execution, error handling, and unit test coverage.

## Project Structure
```text
01_cli_calculator/
├── app/
│   ├── __init__.py
│   ├── main.py
│   └── calculator.py
├── tests/
│   ├── __init__.py
│   └── test_calculator.py
├── pyproject.toml
├── requirements.txt
└── README.md
```

## How to Run
```bash
python -m app.main 10 + 20
```

## Running Tests
```bash
pytest tests/
```

# Mini Project: Advanced Metaclass, Descriptor & AST Static Linter Engine

## Overview
In this mini project, you will build an Advanced Python Framework combining custom Descriptors (for attribute validation), Metaclasses (for dynamic schema registration), and AST static analysis (for code structure verification).

## Features
- **Validated Field Descriptor**: Enforces type and range validations on class attributes.
- **ORM-Style Metaclass**: Automatically registers field descriptors and constructs model schemas.
- **AST Static Code Linter**: Parses source code AST to audit function naming rules.

## Running the Engine
```bash
python main.py
```

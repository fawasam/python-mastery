# Advanced Decorators and Decorator Factories

## What You Will Learn
- Building parameterized decorators (Decorator Factories)
- Class-based decorators implementing `__call__`
- Preserving function metadata (`@functools.wraps`)
- Decorating methods vs standalone functions

## Why This Matters
Decorators allow cross-cutting concerns (logging, authentication, retry logic, rate limiting, transaction management) to be cleanly injected without cluttering core business functions.

# Mini Project: Automated Log Archiver and Disk Auditor

## Overview
In this mini project, you will build an automated system maintenance script that scans a target log directory, identifies outdated `.log` files older than a configurable threshold, compresses them into `.zip` archives, and generates an audit report.

## Features
- Scans target directory for `.log` files.
- Compresses log files into a zip archive with timestamped naming.
- Audits system disk space before and after archiving.

## Running the Script
```bash
python main.py
```

# System Automation & Subprocess Control in Python

## What You Will Learn
- Executing system shell commands safely using `subprocess.run()`
- Capturing command stdout, stderr, and return codes
- Monitoring system resources (CPU, Memory, Disk space)
- Managing cross-platform OS paths and environment settings

## Why This Matters
Python acts as the ultimate glue language, automating shell scripts, invoking external binaries, monitoring host metrics, and orchestrating system deployments.

## Core Modules
- `subprocess`: Executing child processes and commands.
- `shutil`: Disk space and system utility commands.
- `platform` / `sys`: Querying host system specifications.

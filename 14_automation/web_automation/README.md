# Web Scraping & HTML Automation in Python

## What You Will Learn
- Scraping HTML pages using `httpx` / `requests` and `BeautifulSoup` (or pure standard parser)
- Extracting tables, links, and structured elements from HTML
- Handling User-Agent headers, timeouts, and rate limits
- Parsing RSS/XML feeds and JSON API endpoints

## Why This Matters
Web scraping and data harvesting allow developers to monitor price changes, aggregate news feeds, gather competitive analytics, and automate data collection.

## Core Libraries
- `httpx` / `requests`: Fetching web content via HTTP requests.
- `urllib.request` / `html.parser`: Standard library fallback for zero-dependency web parsing.

# Automated File & Directory Operations in Python

## What You Will Learn
- Traversing directory structures using `pathlib.Path` and `os.walk()`
- Batch renaming, organizing, moving, and deleting files safely
- Computing file hashes (`md5` / `sha256`) to identify and remove duplicate files
- Managing zip archives (`zipfile`) and temporary files (`tempfile`)

## Why This Matters
Automating tedious file system tasks (e.g. organizing downloads folders, archiving log files, auditing duplicate media) saves hundreds of hours of manual effort.

## Core Tools
- `pathlib.Path`: Object-oriented filesystem path manipulation.
- `shutil`: High-level file operations (copy, move, delete tree).
- `hashlib`: Hash computing for duplicate verification.
- `zipfile`: Archiving and extracting zip files.

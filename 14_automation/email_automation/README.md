# Automated Email Processing in Python

## What You Will Learn
- Constructing MIME emails using standard library `email.message.EmailMessage`
- Sending HTML emails and attachments via SMTP (`smtplib`)
- Mocking email dispatch during local testing
- Parsing incoming emails via IMAP (`imaplib`)

## Why This Matters
Automating automated notification emails (reports, password resets, alert digests) is essential in modern cloud infrastructure and background task runners.

## Core Standard Modules
- `email.message.EmailMessage`: Building structured plain-text & HTML MIME messages.
- `smtplib`: Connecting to SMTP servers over TLS/SSL.

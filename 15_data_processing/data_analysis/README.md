# Exploratory Data Analysis (EDA) in Python

## What You Will Learn
- Summary statistics (`describe()`, `mean()`, `std()`, `quantile()`)
- Correlation matrix analysis (`df.corr()`)
- Aggregating time series data by rolling windows (`rolling()`)
- Extracting actionable business metrics from datasets

## Why This Matters
Exploratory Data Analysis (EDA) allows developers and data engineers to uncover hidden trends, patterns, correlations, and distributions within data before training machine learning models or building business dashboards.

## Core Metrics
- **Mean & Median**: Central tendency measures.
- **Standard Deviation & IQR**: Variance and spread metrics.
- **Pearson Correlation**: Pairwise linear relationship strength between numerical variables (ranging from $-1.0$ to $+1.0$).

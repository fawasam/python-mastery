# Numerical Computing with NumPy

## What You Will Learn
- Creating and manipulating N-dimensional arrays (`np.ndarray`)
- Array slicing, indexing, and boolean masking
- Vectorized operations vs Python loops
- Array broadcasting rules and linear algebra matrix math

## Why This Matters
NumPy is the foundational backbone of scientific computing, data science, and AI/ML in Python. Vectorized NumPy operations execute C-speed array math up to 100x faster than standard Python loops.

## Core Concepts

### Vectorization
Operating on entire arrays at once without explicit Python `for` loops.

### Broadcasting
NumPy's mechanism for performing element-wise operations on arrays of different shapes.

# Data Analysis & Manipulation with Pandas

## What You Will Learn
- Creating and loading DataFrames and Series
- Selecting data with `.loc[]` (label-based) and `.iloc[]` (index-based)
- Filtering rows, handling missing data (`dropna()`, `fillna()`)
- Grouping and aggregation with `.groupby()`

## Why This Matters
Pandas is the default library for data manipulation, ETL pipelines, tabular data processing, and feature engineering in modern data science workflows.

## Core Concepts

### DataFrame vs Series
- **Series**: 1-Dimensional labeled array holding homogenous data.
- **DataFrame**: 2-Dimensional tabular data structure with labeled axes (rows and columns).

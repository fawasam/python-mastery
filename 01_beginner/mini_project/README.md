# Mini-Project 01: Personal Finance & Expense Tracker CLI

## Project Overview
Build an interactive Command Line Interface (CLI) Personal Finance & Expense Tracker that allows users to record income/expenses, view category totals, calculate financial summary metrics, and save/load transactions from file storage.

## Features
1. **Add Transaction**: Record type (`INCOME` or `EXPENSE`), category (e.g., `Food`, `Rent`, `Salary`), amount, and timestamp.
2. **View All Transactions**: Tabular listing of all recorded entries.
3. **Category Breakdown**: Group and sum expenses by category.
4. **Financial Summary**: Calculate total income, total expenses, net balance, and savings rate percentage.
5. **Persistence**: Automatically save transactions to a text/JSON file on exit and reload them on startup.

## Concepts Demonstrated
- Variables, Data Types & Type Casting
- Conditionals & Guard Clauses
- Loops & Control Directives
- Lists, Dictionaries & Functions
- Exception Handling (`try-except`)
- File Handling (`pathlib`, context managers, file I/O)
